$ llm-capacity-planner Qwen/Qwen3.8-27B --tokens 32k --users 200

Summary
  Recommendation: 1 server with 2× NVIDIA B200 SXM serves 200 users with requests of up to 32k tokens (≈ 25,000 words ≈
      49 pages; 16k on average).
  Alternative: 1 server with 2× NVIDIA B300 SXM (fits; 340 users guaranteed, 540 likely).
  Not enough: L4, even with 8 GPUs in one server; RTX 3090, RTX 4090 and RTX 5080, even with 4.
  Speed for each user: writing about 27 words per second (15 to 39; 36 tokens/s); with everyone busy the first words
      appear after about 1.0 s, and a full 32k-token request alone is read in about 1.3 s (1 token ≈ 0.75 words).
  Confidence: memory high (±6.3%); writing speed medium (±44%); reading time medium (±48%); user count medium (±44%).
      Plan on the guaranteed figures.

Technical detail
Qwen3.8-27B at 32k tokens, fp8 KV cache: serves users from 1× H100 SXM5 80GB, or 1× H100 PCIe 80GB. For 200 users (10%
active ≈ 20 concurrent requests) you need 2× B200 SXM (2 copies × 1), or 2× B300 SXM (2 copies × 1): 340 users
guaranteed, 540 likely, at 36 tok/s (20 to 52, ±44%, estimated) each.
Scenario "documents": each request brings 16k new tokens to read and generates 500; at least 20 tok/s per user. For a
chat (the conversation stays in the cache) use --prompt-cache 80.

Memory per GPU with one request of 32k tokens (≈ 25,000 words ≈ 49 pages): the model's weights and its conversation
memory (KV cache) are computed exactly, the engine's fixed costs are estimated. Margin = room left for more
conversations after that request. Card memory = what CUDA reports (the engine's usable memory; nvidia-smi shows a little
more).
Users: total = concurrent requests ÷ 10% active at once (--active); each gets ≥20 tok/s and the first token within 10 s
(or, if longer, twice the wait for the first words of one typical request alone: half the context, less what the prefix
cache holds).
Users include AI agents. Splitting work across parallel agents or subagents gets it done sooner, but each one is a
concurrent client: 5 subagents count as 5 users. Agents are usually active all the time and send long contexts, so raise
--active and --tokens for agent workloads.
Accuracy: exact = computed; measured = this model on this card; calibrated = fitted on measurements of this card or of
the same model type (N points); estimated = calibrated on other cards, not verified, or extrapolated; not precise enough
to decide = ±50% or more, or a case not covered.
Speed basis (vLLM 0.31.0) of the cards shown: estimated: hybrid BF16 not verified with vLLM, vLLM 0.31.0 (43 points).
Weights: exact as the sum of the tensors; BF16 × hybrid not yet verified by a measurement: 5% margin in the fixed costs.
Multimodal model: with --text-only (vLLM --language-model-only) the vision encoder is not loaded.
